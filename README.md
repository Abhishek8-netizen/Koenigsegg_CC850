# Koenigsegg CC850 Showcase Website

A custom-built showcase website dedicated to the Koenigsegg CC850.  
Created using **HTML**, **CSS**, and **JavaScript**, featuring smooth scrolling, animations, and a dynamic image gallery.

# Features
- Interactive gallery using JavaScript
- Smooth scroll behavior
- Dynamic section reveals with Intersection Observer
- Fully responsive layout
